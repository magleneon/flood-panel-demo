# Паводковая панель (демо)

Демонстрационная страница сервиса, который показывает, что уйдёт под воду в районе Хабаровска при заданном уровне воды на гидропосте.

- Дороги, посёлки, жилые и дачные зоны: © участники OpenStreetMap
- Постоянное русло Амура и проток выделено по снимку Sentinel-2 от 17.10.2026 (Copernicus)
- Высоты в демо условные, цифры показывают работу метода и не являются прогнозом

Открыть: `index.html` (один файл, работает без интернета).
